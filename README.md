_Data & Model_
* AppDatabase.java - Initializes the local Room database
* EventDao.java - Executes local database queries
* EventEntity.java - Defines the database table schema
* remote/ & repository/ - Scaffolding for Python/MySQL backend integration

_User Interface_
* LoginActivity.java - Handles user login logic
* DashboardActivity.java - Controls main dashboard logic
* AnalyticsActivity.java - Controls sponsor metrics logic
* CreateEventActivity.java - Handles event creation logic
* EventAdapter.java - Binds event data to scrollable UI lists
* SponsorOnboardingActivity.java - Handles corporate onboarding logic

_Resources & Configuration_
* AndroidManifest.xml - Declares app screens and system permissions
* layout/ - Draws app UI
* drawable/ - Stores visual assets like icons and backgrounds
* values/ - Defines global colors, text strings, and themes
* mipmap/ - Stores app launcher icons
